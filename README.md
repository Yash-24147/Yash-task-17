# JavaScript Promise Division

## About

This is a simple JavaScript project. I made this project to practice working with Promises, arrow functions, and error handling in JavaScript.

The program performs division of two numbers, handles division by zero, and displays the results.

## Technologies Used

JavaScript

## Features

Divides two numbers using a Promise

Handles division by zero

Displays the result or error message

Tests the function with five different cases

## JavaScript Used

Some basic JavaScript concepts used in this project are

Promises

Arrow functions

resolve()

reject()

then()

catch()

if statement

console.log()

## Operations Performed

1. Division of Numbers

Divides the first number by the second number using a Promise.

2. Division by Zero

Checks if the second number is zero and displays an error message.

3. Promise Handling

Handles successful results using then() and errors using catch().

## How to Run

Create a JavaScript file named script.js.

Add the JavaScript code to the file.

Run the file using Node.js or open it in a browser console.

Check the results in the console.
